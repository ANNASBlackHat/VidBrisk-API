# Default Style (General Purpose)

## Tone & Mood
- Neutral to slightly engaging. Let the script content set the emotional tone.
- Default mood: `neutral`.

## Beat Type Preferences
- Mix `narrative` (concrete facts/story), `stat` (numeric data), and motion
  types for variety.
- Avoid over-using `kinetic` or `swipe_deck` — reserve for genuine list
  or high-energy moments.

## Visual Intent
- Match the literal subject of the narration as closely as possible.
- For abstract concepts, find a concrete physical metaphor
  (e.g. "interconnected global supply chain" → "aerial view of cargo port with trucks").
- Prefer footage with camera movement or subject action over static locked-off shots.
- When exact footage is unlikely to exist, state the closest available real analog.
